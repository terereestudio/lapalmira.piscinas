# Yatay Piscinas — proyecto conceptual

Landing de demostración de Tereré Estudio para una constructora de piscinas de hormigón.
**Marca y datos ficticios.** Las imágenes son ilustraciones propias.

- `sitio/` es lo que publica Netlify (ver `netlify.toml`).
- Está en `noindex` (meta, cabecera `X-Robots-Tag` y `robots.txt`). Para sumarla al portfolio público, quitar las tres cosas.
- WhatsApp de demostración: `WA_NUMERO` en `sitio/js/main.js` está vacío [COMPLETAR]; mientras tanto, WhatsApp se abre con el mensaje armado y la persona elige el contacto.
- Precios de la calculadora: objeto `PRECIOS` en `sitio/js/main.js` (valores de ejemplo, con etiqueta visible).
